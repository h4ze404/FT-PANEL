# AFBaritone — Авто-рыбалка + Baritone (Minecraft 1.21.1)

Fabric-мод: сам находит ближайшую воду, просит Baritone подойти к ней, закидывает
удочку и автоматически подсекает/вытаскивает рыбу.

## Состав

- Готовый мод: `build\libs\afbaritone-1.0.0.jar`
- Исходники: `src\`
- Пересборка: JDK 21 + Gradle 8.10.2 (`C:\dvtools` / `D:\Чит\tools`), команда `gradle build`

## Установка

1. Установи Fabric Loader для 1.21.1 (https://fabricmc.net/use/installer/)
2. Скачай Fabric API для 1.21.1 и положи `.jar` в папку `mods`
3. Скачай Baritone для 1.21.1 (`baritone-fabric...jar`) и положи в `mods` тоже
   — без него мод работает, но сам не ходит к воде
4. Положи `afbaritone-1.0.0.jar` в `.minecraft\mods`
5. Удочка должна лежать в хотбаре (1-9 слоты)

## Использование

| Клавиша | Действие |
|---------|----------|
| **O**   | Открыть настройки AFBaritone |
| **V**   | Быстрый старт/стоп (искать воду вокруг себя) |

В настройках (клавиша **O**):
- **X, Y, Z** — цель, куда идти через Baritone (пусто = текущая позиция)
- **Радиус** — радиус поиска воды (по умолчанию 32 блока)
- **«Пойти и рыбачить»** — запустить: Baritone доведёт до цели, затем мод найдёт
  ближайшую воду, подойдёт (если далеко), прицелится и начнёт рыбалку
- **«Стоп»** — остановить (тоже останавливает Baritone, если он был запущен)

Логика: цель → (Baritone `#goto`) → поиск ближайшей воды с воздухом сверху →
если вода дальше ~14 блоков, Baritone подходит к берегу → выбор удочки в хотбаре →
прицел на воду → закинуть → детект поклёвки (рывок поплавка) → подсечка →
пауза ~1 сек → снова закинуть. Круг повторяется бесконечно, пока не нажмёшь «Стоп».

## Важно

- Работает в одиночке и на серверах, но использование авто-рыбалки/Baritone
  на публичных серверах может нарушать их правила — проверь заранее.
- Baritone перехватывает команды с префиксом `#` на стороне клиента,
  поэтому моду не нужна отдельная интеграция: он отправляет `#goto x y z`.
